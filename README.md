# AirBoard Pro 2.0

## Instalação
1. Instale Node.js LTS.
2. Abra o terminal nesta pasta.
3. Rode: `npm install`
4. Rode: `npm start`
5. No PC/TV abra `http://localhost:3000`.
6. Clique em **Conectar** e escaneie o QR Code.
7. PC/TV e celular devem estar na mesma rede Wi-Fi.

## Recursos
- QR Code com IP local automático
- Celular/tablet como controlador
- Desenho em tempo real
- Caneta, marca-texto e borracha
- Linha, retângulo, círculo e texto
- Ponteiro laser
- Limpar
- Salvar PNG
- Tela cheia/apresentação
- Salas via Socket.IO

## Observação
É uma V2 funcional/MVP. Recursos avançados como persistência completa, PDF/slides, autenticação, múltiplos alunos e IA podem ser adicionados na V3.
